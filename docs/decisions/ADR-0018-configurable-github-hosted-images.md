# ADR-0018: Select an ordinary GitHub-hosted CI image

Status: Accepted

Date: 2026-11-08

Decision owners: Bootstrap maintainers

Decision record: the repository owner approved the concrete ownership/runner boundary for [Bootstrap #63](https://github.com/OMT-Global/bootstrap/issues/63). The task coordinator selected this bounded compatibility implementation. Approval authorizes source preparation and local migration validation, not settings changes, merges, tags, or releases.

## Context

Bootstrap's reviewed ordinary hosted CI jobs use Ubuntu 24.04. The generator previously hardcoded `ubuntu-latest`, so truthful dogfood adoption would overwrite that choice. The runner policy already chooses between hosted execution and capability-labelled self-hosted pools; image selection should not change that policy.

## Decision

Add optional `ci.githubHostedImage` with exactly `ubuntu-latest` and `ubuntu-24.04`. An absent field remains absent in normalization/serialization and resolves to `ubuntu-latest`, preserving legacy generated bytes. Pass the choice through the existing hosted fallback and direct ordinary CI/security/Claude jobs. Advanced CodeQL conformance expects the selected Linux matrix entry while Swift keeps macOS. The existing simple release caller passes the selected image through its already-supported `runs-on` input.

Retain capability routing, self-hosted labels, event restrictions, token permissions, and immutable references. Governed release caller/reusable contracts and shared AI-attestation calls keep their existing behavior; this field supplies no unsupported remote input or platform override. Those workflow contracts require a separate compatible change if a caller needs a different release runner.

## Validation and consequences

Regression coverage checks schema rejection, optional-field round-tripping, exact default output equivalence, capability routing, direct-job selection, read-only public security events, Swift preservation, governed/shared contract identity, doctor output, and successful applied security conformance followed by rejection of an inconsistent CodeQL matrix entry. Full repository checks and actual-base autoreview are required before publication; independent GitHub approval remains separate.

This is the source prerequisite. The approved 47-path managed ownership inventory and project-owned README/three release hooks are applied only in a separately validated migration after the fleet backend parent is frozen. Existing first-party license bytes and legal approvals are unchanged.
