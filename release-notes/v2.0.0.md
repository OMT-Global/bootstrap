# Bootstrap v2.0.0

Bootstrap manages repository files, GitHub governance, CI, and portable agent profiles from `project.bootstrap.yaml`. This release distributes the source for Bootstrap’s CLI and repository templates. Building the CLI requires Node.js 20 or later.

## Repository policy

- Preview repository, GitHub, and home-profile changes with `bootstrap plan` and apply each target separately. Bootstrap records ownership of generated files and flags direct edits before applying changes.
- Use `bootstrap conform` to check repository class, managed files, action pins, public security, licensing, and documented policy exceptions. Flow policy pins bind to a specific bundle digest. [#257](https://github.com/OMT-Global/bootstrap/pull/257)
- Explicit issue labels override Flow defaults case-insensitively. If a manifest explicitly defines two names that differ only by case, keep the spelling and metadata you intend to use and remove the duplicate. [#258](https://github.com/OMT-Global/bootstrap/pull/258)

## CI and provenance

- Public repository security jobs use GitHub-hosted runners. The workflow configuration supports CodeQL, dependency review, and software bills of materials.
- Signed public provenance binds reviewer evidence to the repository and exact commit. Read-only fleet inventory reports policy pins and managed-file drift from a trusted generator checkout. The separate upgrade planner uses recorded pilot results to determine eligibility for each class. [#260](https://github.com/OMT-Global/bootstrap/pull/260), [#259](https://github.com/OMT-Global/bootstrap/pull/259), [#255](https://github.com/OMT-Global/bootstrap/pull/255)

## Release workflow

- When configured for approved source publication, the workflow verifies the exact release package, including the committed release notes and asset checksums, before publishing. Major and minor compatibility tags move through a separate operation that verifies the published package. [#267](https://github.com/OMT-Global/bootstrap/pull/267), [#271](https://github.com/OMT-Global/bootstrap/pull/271)
- An exact-match retry verifies an existing release against its currently approved package. A mismatch or uncertain result requires operator reconciliation. [#266](https://github.com/OMT-Global/bootstrap/pull/266)

## Build from source

Download `bootstrap-v2.0.0-source.tar.gz` and verify it against `bootstrap-v2.0.0-source.tar.gz.sha256` before unpacking. Run `npm ci --ignore-scripts` and `npm run build` in the extracted directory. Use `node dist/cli.js plan --manifest ./project.bootstrap.yaml --target .` to inspect the plan before applying changes.

See the [Bootstrap repository](https://github.com/OMT-Global/bootstrap) for onboarding and release operator documentation.
